# AI Lab Programs - Questions 9 to 15

Run any script with `python <file>.py` from inside its folder.

| Q  | Folder / Script(s) | Topic | Libraries |
|----|--------------------|-------|-----------|
| 9a | Q09_first_order_logic/q09a_backward_chaining.py | FOL backward chaining | stdlib |
| 9b | Q09_first_order_logic/q09b_forward_chaining.py  | FOL forward chaining  | stdlib |
| 10a-d | Q10_nltk_processing/q10a..q10d_*.py (+ sample_passage.txt) | Stop words, stemming, POS tagging, lemmatization | nltk |
| 11 | Q11_text_classification/q11_text_classification.py | Naive Bayes text classification | nltk |
| 12 | Q12_ann_classification/q12_ann_classification.py | ANN (MLP) on Iris | scikit-learn, numpy |
| 13 | Q13_genetic_algorithm/q13_genetic_algorithm.py | GA: binary, real-valued, permutation genes | stdlib |
| 14 | Q14_bayesian_network/q14_bayesian_network.py | Bayesian network inference | stdlib |
| 15 | Q15_backpropagation/q15_backpropagation.py | Backpropagation from scratch (XOR) | numpy |

## Setup
    pip install nltk numpy scikit-learn

The NLTK scripts download their needed data automatically on first run
(an internet connection is needed once).
